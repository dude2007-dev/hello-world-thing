# Hello World Bot

CLI-генератор ASCII-арта на Python с чистой архитектурой.

## Стек

- Python 3.10+
- pyfiglet
- pytest (для тестов)

## Установка

```bash
git clone https://github.com/твой_ник/hello-world-bot.git
cd hello-world-bot
python -m venv venv
venv\Scripts\activate      # Windows
pip install -e .[dev]

## Тест
python -m pytest -v
